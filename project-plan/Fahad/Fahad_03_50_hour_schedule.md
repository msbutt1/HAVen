# Fahad: 50-hour schedule

Hour 0–1: agree scope, inventory, contracts, ownership, and example data with the team. Then start independently.

## Hours 0–4
Build the simulated motor/button adapter and station state machine.

## Hours 4–10
Implement felt/not-felt responses, missing-response timeouts, reversal tracking, and abort.

## Hours 10–18
Connect real motor commands with Collins and Salaar; save results through Abduljabbar.

## Hours 18–28
Finish the full station workflow and end-to-end test harness; draft the demo narrative.

## Hours 28–36
Run complete demos, log failures, draft slides, and capture a working backup.

## Hours 36–43
Coordinate rehearsal, backup video, and submission; collect material from every teammate.

## Hours 43–50
Rehearsal, rest, final fixes, packing, and submission buffer. No new features.

## Shared checkpoints
- Hour 4: every subsystem runs independently with mocks.
- Hour 10: real wearable reading reaches the dashboard.
- Hour 18: wearable session saves and station commands operate the motor.
- Hour 28: both journeys work end to end.
- Hour 36: three successful full runs and feature freeze.

Stagger rest around handoffs; these are elapsed milestones, not uninterrupted work shifts.
